# **App Name**: VR Point Shooter

## Core Features:

- VR Scene Display: Display a VR scene with floating spheres and a crosshair.
- Targeting and Scoring: Implement sphere flashing and disappearing upon crosshair collision, awarding points.
- Cardboard VR Toggle: Add a toggle switch to optimize the display for Google Cardboard VR.
- Motion Sensor Data: Utilize Android WebView for motion sensor data

## Style Guidelines:

- Primary color: Dark gray (#222) for the background to enhance the VR immersion.
- Secondary color: Light gray (#EEE) for UI elements to ensure readability.
- Accent: Bright green (#00FF00) for the crosshair and score display to provide clear visual cues.
- Simple, uncluttered layout to maximize focus on the VR environment.
- Minimalist icons for the Google Cardboard toggle switch.
- Quick flash animation for spheres upon hit.
